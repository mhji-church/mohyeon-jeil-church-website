# 익명 접속 통계 운영 메모

이 기능은 현재 로컬 작업 트리에만 있습니다. 운영 DB에 `0003_anonymous_analytics.sql`을 적용하거나 배포한 상태가 아닙니다.

## 수집과 접근

- 공개 페이지에서 짧은 묶음으로 `POST /api/analytics/collect`를 보냅니다. 수집 실패는 페이지 렌더링과 기존 기능에 영향을 주지 않습니다.
- 최초 정상 수집 때 임의의 서명된 HttpOnly/SameSite 쿠키를 발급합니다. 회원 ID, 원본 IP, 원본 User-Agent, URL 쿼리, 검색어, 외부 referrer 전체 URL은 통계 DB에 저장하지 않습니다. 이 쿠키는 최대 400일이며 쿠키를 지우거나 기기를 바꾸면 다른 방문자로 계산됩니다.
- 관리자 세션의 공개 페이지 방문, 관리자 경로, API 및 정적 요청은 제외합니다. 알려진 봇은 User-Agent로 제한적으로 걸러내며 완전한 봇 제거는 보장하지 않습니다.
- 보고서 페이지/API/CSV는 서명된 아카이브 관리자 자격증명 슬롯에만 허용됩니다. 현재 관리자들은 DB 회원 행이 아니라 서로 다른 서버 환경변수 자격증명 슬롯으로 정의됩니다. 일반 회원의 같은 표시 이름/아이디는 권한 판정에 사용하지 않습니다.
- 국가 코드는 Netlify 함수의 신뢰 가능한 `getContext().geo.country.code`가 있을 때만 기록하고, 그렇지 않으면 `ZZ`(알 수 없음)입니다.

## 집계·보관

- KST 날짜와 월요일 시작 주를 사용합니다. 30분 비활동 시 새 세션입니다. 최근 400일의 세션·이벤트에서 선택 기간 고유 방문자를 중복 제거합니다.
- 기간에 오래된 날짜가 포함되면 일별 누적 방문/조회 집계로 연간·누적 흐름을 유지합니다. 보관 기간 밖의 중간 기간 방문자 및 추이의 방문자 값은 정확한 기간별 중복 제거가 불가능하므로 추정으로 표시합니다. 전체 수집 기간의 고유 익명 ID 수는 최초 방문 일별 집계의 합으로 유지합니다.
- 원본 이벤트·세션·최근 방문자 키·수집 빈도 제한 행은 400일(빈도 제한은 더 짧게) 보관하며, 일별 합계는 장기 보관합니다. 정리는 첫 정상 수집 시 하루 한 번 인덱스 기준으로 실행합니다. 별도 주기적 전체 재집계는 없습니다.
- 보고서는 프로세스당 최대 60초 메모리 캐시를 사용하며 자동 초 단위 폴링은 없습니다. 요청·응답과 CSV는 `private, no-store`이며 서비스워커는 `/api/`와 `/admin`을 캐시하지 않습니다.

## 비용 추정과 한계

일반적인 한 페이지 조회는 수집 함수 요청 약 1회와 이벤트 행 1개를 추가합니다. 100방문/일에 평균 3페이지라면 대략 300 수집 요청/일, 기본 조회 이벤트 약 300행/일, 400일 보관 기준 약 12만 조회 이벤트 행에 행동 이벤트가 더해집니다. 실제 수치는 체류, 탭 종료 전송, 재시도, 행동 횟수에 따라 달라집니다. 외부 유료 분석 서비스는 사용하지 않습니다.

기존 사이트에는 사업장 별도 상세 화면과 주보 다운로드 버튼이 없어서 해당 이벤트는 임의로 만들어 집계하지 않습니다. 현재는 사업장 외부 링크·주보 열람을 기록합니다. 영상 열기는 시청 완료로 계산하지 않습니다. 검색어, 카카오 내부 전달 경로, 기기 모델은 추정하지 않습니다.

## 배포 전 확인

- `npm run db:migrate:validate`는 새 임시 DB와 기존 스키마 모사 DB에서 반복 적용을 확인합니다. 운영 DB 마이그레이션/백업·롤백 방법을 검토하고 별도 배포 승인을 받은 뒤 적용해야 합니다.
- 자동 익명 쿠키를 쓰므로 적용 전 현행 개인정보 처리방침·수집 근거·거부 안내의 적합성을 법률/개인정보 담당자가 확인해야 합니다. 다른 사이트가 동의 없이 운영한다는 사실만으로 이 사이트의 법적 요건이 확정되지는 않습니다. 기존 개인정보 문구는 이 작업에서 변경하지 않았습니다.
- 배포 전 관리 자격증명 환경변수 `ADMIN_USERNAME`, `ARCHIVE_ADMIN_USERNAME`, 각 비밀번호, `ADMIN_SESSION_SECRET`이 기존 방식대로 구성되어 있는지 값 출력 없이 확인합니다. 추가 비밀 환경변수는 요구하지 않습니다.
