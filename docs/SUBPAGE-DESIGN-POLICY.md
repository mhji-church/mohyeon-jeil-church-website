# 모현제일교회 하위 페이지 제작 원칙

## 1. 공통 구조

모든 연결 페이지는 메인 홈페이지와 같은 공통 헤더, 로고, 메뉴, 푸터를 사용한다. 페이지마다 별도 스타일을 만들지 않고 공통 컴포넌트와 디자인 토큰을 우선 재사용한다.

기본 순서는 다음과 같다.

1. 공통 고정 헤더
2. 영문 분류명과 한글 페이지명이 들어간 서브 비주얼
3. 현재 대분류의 하위 메뉴 탭
4. 페이지 핵심 콘텐츠
5. 목록형 페이지의 페이지 이동 또는 더보기
6. 관련 메뉴 연결
7. 공통 푸터

## 2. 시각 기준

- 기본 배경: 아이보리 계열 `#fffdf9`
- 본문색: 짙은 남보라 계열 `#302f3c`
- 강조색: 브라운 `#a97161`, 피치 `#e7c2ad`
- 제목은 메인과 같은 굵기와 좁은 자간을 유지한다.
- 본문 최대 폭과 좌우 여백은 메인의 `.page-width`를 사용한다.
- 새 사진은 임의 이미지가 아니라 교회 제공 원본 또는 해당 콘텐츠의 공식 썸네일만 사용한다.

## 3. 반응형 기준

- PC는 정보량에 따라 2~3열, 모바일은 반드시 1열로 정리한다.
- 썸네일과 영상은 모두 16:9를 유지한다.
- 모바일 헤더는 고정하고 하위 메뉴는 펼침 방식으로 제공한다.
- 버튼과 링크의 최소 터치 영역은 44px를 기준으로 한다.
- 긴 제목은 2줄까지만 보여 주고, 중요한 날짜와 분류는 숨기지 않는다.

## 4. 목록·상세 페이지 기준

- 목록 카드에는 날짜, 분류, 제목, 대표 이미지와 원문 이동 링크를 포함한다.
- 영상은 사이트 안에서 재생할 수 있게 하고 유튜브 원본 이동 링크를 별도로 둔다.
- 주보, 교회소식, 갤러리는 목록 페이지와 상세 페이지의 주소를 분리한다.
- 기존 `mhji.kr` 주소가 검색 결과에 남아 있는 경우 같은 주소를 우선 유지하거나 새 주소로 301 이동한다.

## 5. 앞으로 제작할 페이지

- 교회 소개: 인사말, 교회 연혁, 섬기는 사람들, 예배 안내, 오시는 길
- 주보: 연도·월 필터가 있는 목록과 PDF·이미지 상세 보기
- 교회소식: 목록과 상세 글
- 성도사업장: 업종 필터와 사업장 카드
- 갤러리: 행사별 앨범 목록과 사진 상세 보기
