# 카페24 이전 및 운영 계획

## 목표

현재 임시 Sites 주소는 제작·검수용으로만 사용한다. 모든 메뉴와 콘텐츠 이전이 끝나면 동일한 소스 기준으로 카페24 서버에 배포하고 `mhji.kr`을 연결한다.

## 이전 전제

- 워드프레스 파일과 데이터베이스는 새 사이트 공개 전에 삭제하지 않는다.
- 기존 워드프레스의 게시물, 주보, 갤러리, 첨부파일을 먼저 백업하고 새 구조로 옮긴다.
- 새 사이트의 모든 메뉴와 기존 주소 대응표를 검수한 뒤 도메인을 전환한다.
- 웹사이트용 A·CNAME 레코드만 변경하고 이메일용 MX·TXT 레코드는 유지한다.

## 권장 배포 방식

1. 현재 소스를 Git 저장소의 기준본으로 유지한다.
2. 카페24에서 Node.js 배포가 가능한 상품을 사용한다.
3. 저장소의 변경 내용을 카페24 배포 환경에 자동 반영한다.
4. 운영용 환경 변수와 비밀값은 소스에 넣지 않고 카페24 설정에서 관리한다.
5. `mhji.kr`과 `www.mhji.kr`을 연결하고 SSL을 발급한다.

일반 웹호스팅만 사용할 경우에는 최종 단계에서 정적 배포판을 별도로 생성한다. 이 경우 서버 기능이 필요한 관리자, 검색, 게시물 등록 기능은 별도 API나 지원 가능한 호스팅 상품이 필요하다.

## 최종 전환 순서

1. 워드프레스 서버 파일, 데이터베이스, 업로드 원본 전체 백업
2. 새 사이트의 모든 하위 페이지와 기존 콘텐츠 이전
3. 카페24 테스트 주소 또는 서브도메인에 새 사이트 배포
4. PC·모바일, 영상, 지도, 기존 주소, 검색 노출 점검
5. `mhji.kr` DNS를 새 배포 환경으로 전환
6. 최소 2주 동안 기존 워드프레스 백업 유지
7. 문제가 없을 때 워드프레스와 불필요한 호스팅 정리

- 기존 주소와 새 주소 대응표
